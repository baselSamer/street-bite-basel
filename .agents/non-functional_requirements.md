## Non-Functional Requirements

- Publish the complete Flutter project in a public GitHub repository with a professional README covering the app, architecture, setup, permissions, and App Distribution evidence.

- Enforce Clean Architecture with clearly separated Data, Domain, and Presentation layers.

- Keep each screen, BLoC/Cubit, use case, repository, model, service, and reusable widget in its own Dart file.

- Provide fromJson/toJson factory constructors for API and Firestore models.

- Comment on where and why each design pattern is used.

- Catch network, and Firebase show friendly messages; avoid unhandled exceptions.

- Verify responsive UI on at least two screen sizes using MediaQuery.

- Avoid duplicate code and hard-coded strings; keep text in ARB files.

- Run dart format ., remove unused code/imports/ARB entries, and use feature-specific automation classes sharing BaseTest.
